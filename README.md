## Blockchain Infrastructure (The Hard Years)

### NEO / Credain — 10M Transactions
**[Credain/neo](https://github.com/Credain/neo)** · **[enkayxyz/credain-g0](https://github.com/enkayxyz/credain-g0)**

The FX netting engine. RTN™ algorithm uses graph-theory loop detection to find multilateral netting opportunities across corporate treasury corridors in real time.

- Scaled to **10M transactions** on EVM/Avalanche
- IFSCA regulatory sandbox approval (India)
- 12+ Tier-1 demos: Aramco, GE Healthcare, PepsiCo, NTT, Alstom
- Patent application filed

What broke at scale: gas optimization, state management, enterprise key custody.  
What I built to fix it: BEAM.

### BEAM
Enterprise-ready access layer on top of the blockchain stack.  
Built on **EIP-4337 account abstraction** on **Avalanche**.  
Solved: compliance, access control, enterprise key management.  
Status: ~20% built, open-source release planned. Code runs end-to-end.
